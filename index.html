SIR Model Explanation

This simulation is based on the classical SIR epidemiological model, which divides a closed population into three compartments: Susceptible (S), Infected (I), and Recovered (R).

At each time step, the model updates these values using the following equations: 

new infections = β × S × I / N
new recoveries = γ × I

S(t+1) = S(t) − new infections
I(t+1) = I(t) + new infections − new recoveries
R(t+1) = R(t) + new recoveries

Here, β represents the infection rate and γ represents the recovery rate. The total population N is assumed to remain constant.

This project visualizes these abstract equations by mapping individuals to moving emojis, allowing the mathematical behavior of the model to be observed intuitively.

Limitations

The SIR model assumes homogeneous mixing, equal susceptibility, and no births or deaths. It does not account for age structure, spatial clustering, reinfection, or public health interventions. Despite these limitations, it provides a strong conceptual foundation for understanding epidemic dynamics.

Epidemic Spread
Epidemic spread describes how infectious diseases propagate through a population over time. Transmission depends on contact frequency, proximity, and probability of infection. Real factors include mobility, social behavior, and environment.
Model Types
Epidemiology uses multiple modeling approaches. SI, SIR, SEIR, and agent-based models balance simplicity and realism differently.
Why SIR?
The SIR model balances simplicity and explanatory power. It captures essential epidemic behavior while remaining mathematically transparent and computationally efficient.
Future Improvements
Future extensions could include vaccination, immunity loss, age-stratified populations, or network-based contact patterns.
